# LAPA World — Capitolo 1

Approved by user in conversation: build and publish a new public GitHub repository, following the proposed first chapter for a preschool child and Joy. Preserve existing Joy game.

## Experience
An original interactive miniature 3D LAPA depot and town, inspired by the supplied image. Red branded delivery trucks, open warehouse with ambient/chilled/frozen bays, a road, pizzeria, bakery, trees, mountains and an Italian/Swiss setting. Full-screen game, touch-first with desktop keyboard support.

Profiles have editable nicknames, a mode (little driver or explorer), and separate locally saved stars. Five levels per mode. Loop: select level, load the requested products/quantities, hold a large drive control to follow the route, unload matching products at the customer, answer an age-appropriate quantity question in explorer mode, then receive stars and unlock the next level. Wrong attempts are gentle and retryable. Saving happens only after successful completion. Replaying cannot farm progress or penalize the player. Speech instructions optional, synthesized only after interaction; sound toggle, reduced motion, responsive controls and keyboard focus.

First chapter does not implement adult strategy, horse activities, online AI, multiplayer or cloud accounts. These are future separate chapters, not nonfunctional buttons.

## Delivery
Vite + Three.js + plain JavaScript/CSS. Small offline-bundled assets and local fonts. PWA with app icons, offline precache, update prompt and install help. Public GitHub repository under authenticated owner; publish playable GitHub Pages URL. Name entered by player remains on device. No business data, private assets beyond authorized LAPA logo, credentials or family details published. Complete desktop and mobile browser flow checks, progress isolation and offline reload checks before claiming completion.

## Visual direction
Living toy town is the dominant element. Palette: LAPA red #D83B35, forest #234D3E, sky #BAE1F1, grass #A7CD7C, butter #F5D87C, paper #FFFDF5. Baloo 2 headings and Nunito body, locally served. Die-cut tactile controls, illustrated functional product buttons, quiet dark-green text. World provides the spectacle; interface stays compact and usable. Mobile scene above task panel; desktop scene fills viewport behind task panel. No marketing landing page.
